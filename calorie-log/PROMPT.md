## Расход и баланс

**Расход дня** = база сидячая **~2250** + активность:

| Тип | Формула |
|-----|---------|
| **Бег** | ккал **из Garmin** (не считать повторно по км) |
| **Ходьба** | км = **шаги ÷ 1330**; если был бег — **км ходьбы = км по шагам − км бега**; ккал = **MET 3,5 × 89,5 кг × км / 5** |
| **Силовая** | ккал **из сообщения пользователя** (Garmin / оценка). Если **не** названы в **первом** сообщении с тренировкой — журнал **оценивает сам** (MET × 89,5 кг × часы). Пользователь может поправить число. |
| **Прочее** | MET × вес × время |

**Баланс ккал** = расход − приход (еда).

**Жир тела (оценка):** Δ ≈ баланс ÷ **7700** × **1000 г**. Дефицит → «скинул ~X г», профицит → «набрал ~X г». Это **не** жир в еде; вода/гликоген не учитываются.

Источник ккал силовой «журнал оценивает сам»: Николай Павлов, чат 2026-10-06 · если число **не** в первом сообщении с тренировкой.

## Архив дня (`archive/YYYY-MM-DD.md`)

Структура:

1. **Активность** — таблица: тип · детали · ккал; сумма; база + активность = расход.
2. **Еда** — таблица: # · позиция · допущение · Ккал · Б · Ж · У · К; итого; таблица «норма / съедено / баланс».
3. **Источники** — каждая позиция: продукт, база на 100 г, ссылка, отсылка к прошлым дням («как DD.MM #N»).
4. **Баланс (промежуточный)** — КБЖУ, расход, баланс ккал, жир тела.

**Силовую** пиши развёрнуто: упражнения + **отказные подходы по группам** + ккал. Не «силовая ~N ккал» одной строкой.

**Статус дня:** открыт / закрыт. **При открытии нового дня автоматически закрывай предыдущий** (статус **закрыт**; еда/активность/баланс — итог; без доп. записей, если пользователь сам не пишет в закрытый день).

**Дубликаты:** если пользователь дважды отправил одно и то же — удалять лишние позиции по запросу, пересчитывать итог.

## Тренировки

Отдельный учёт. Неделя **с воскресенья по субботу**. Файл недели: `workouts/YYYY-MM-DD.md` (дата **воскресенья** недели).

### Цели недели

| Параметр | Цель |
|----------|------|
| **Бег** | **25 км / неделю** |
| **Отказные подходы** | **20 / неделю** на **каждую** группу |
| **Берпи / Тайсон** | **200 шт / неделю** (сумма: берпи **или** отжимания Тайсона) |

### Группы

Бицепс · Трицепс · Плечи · Грудные · Спина · Ноги · Пресс

**Отказный подход** — сет до отказа + отдых **≥60 с** до следующего такого сета.

### Миостимул (правило чата 2026-10-24; было 2026-10-21 / 2026-10-10 / 2026-09-22)

| Что | В леджер **с 24.10.2026** |
|-----|----------|
| Классический отказной сет | **1** |
| **Миостимул, 2 мини** в кластере | **×1,5** |
| **Миостимул, 3 мини** в кластере | **×2** |
| **Миостимул, 4 мини** в кластере | **×2,25** |
| Мини-отказ внутри кластера (пауза 5–40 с) | **0** (не считать отдельно) |

Если число мини **не** названо — **уточнить у Николая**. Не подставлять 3 мини / ×2.  
**На несколько групп:** множитель **к каждой** задействованной группе.  
Пример **с 24.10:** **4** миостим **3 мини** **спина + грудь** → **+8** спина и **+8** грудные. **5** × **2 мио** жим гантелей вверх → плечи **7,5** · трицепс **3,75**. **5** брусья × **4 мини** → грудь **11,25** · трицепс **11,25** · плечи **5,625**.

**Неделя 18–24.10 целиком** считается по шкале **с 24.10** (в т.ч. подтягивания 21.10: 10×1,5 → спина **15** · бицепс **7,5**).  
**До 17.10 включительно** (неделя 11–17.10 и раньше): **не** пересчитывать. До 20.10 в тех неделях было **2 мини = ×1,5**, **3 мини = ×2**.

Обоснование шкалы с 24.10: экстраполяция с убывающей отдачей (2 мини +0,5 · 3 мини +0,5 · 4 мини +0,25). Источник: Николай Павлов после разбора исследований, чат 2026-10-24 · Bradshaw et al. 2026 — https://pubmed.ncbi.nlm.nih.gov/42112925/ · Pelland et al. 2025 — https://doi.org/10.1007/s40279-025-02344-w. Шкала 21.10: чат 2026-10-21. Шкала до 20.10: чат 2026-10-10 16:28.

### Дробный учёт (правило чата 2026-09-27)

Если названо **упражнение**, а не готовые числа по группам — кредиты считает журнал:

| Роль | За 1 отказной сет (отказ + отдых ≥60 с) |
|------|----------------------------------------:|
| Прямой движитель | **1** |
| Синергист | **0,5** |
| Стабилизатор | **0** |

Без локального отказа (только общая усталость) группы = **0**. Миостимул **с 24.10:** кредит группы **×1,5** (2 мини), **×2** (3 мини) или **×2,25** (4 мини). Если мини **не** названы — уточнить у Николая. Неделя **18–24.10** целиком по этой шкале. Более старые недели не трогать. Явные числа пользователя («5 плечи») не пересчитывать. Каталог: [workouts.md](workouts.md).

| Упражнение | Кредиты за 1 отказной сет |
|------------|---------------------------|
| Брусья | грудь **1**, трицепс **1**, плечи **0,5** |
| Отжимания на кольцах (rings dips) | грудь **1**, трицепс **1**, плечи **0,5** (как брусья) |

| Жим гири от груди вверх | плечи **1**, трицепс **0,5** |
| Жим гантелей двумя руками вверх (стоя/сидя) | плечи **1**, трицепс **0,5** (как жим гири; не жим лёжа) |
| Берпи | группы **0**; только счётчик берпи/Тайсон (шт.) |

| Отжимания (обычные) | грудь **1**, трицепс **1**, плечи **0,5**; счётчик берпи/Тайсон **не** трогать |

| Приседания | ноги **1** |

### Берпи / Тайсон (правило чата 2026-09-23 + 2026-10-06)

- Недельная цель: **200 шт / нед** = **берпи + отжимания Тайсона** (сумма штук). Строка в сводке отдельно от бега и групп.
- **Берпи** (в т.ч. с махом гири) **не** считаются отказными, миостимулом и **не** идут в группы.
- **Отжимания Тайсона:** штуки идут в тот же счётчик; отказные кредиты по каталогу (грудь **1** · трицепс **1** · плечи **0,5** за отказной сет) **не отменяются**.
- **Отжимания обычные:** те же отказные кредиты, что Тайсон; в счётчик берпи/Тайсон **не** идут (чат 2026-10-10).
- Ккал берпи: оценка MET или из сообщения пользователя; писать в **активность дня** (`archive/`), не в отказные.
- Оценка по умолчанию (если нет Garmin/ккал от пользователя): MET **~9–10** × 89,5 кг × часы; 100 берпи + KB 16 кг ~12–15 мин → **~200** (±50).
- Ккал Тайсона: если пользователь **не** назвал число в первом сообщении — журнал оценивает сам (06.10: MET **~8** × 89,5 × **~0,25 ч** → **~180** ±40). Пользователь может поправить.
- Цвета факта берпи/Тайсон: 🟢 ≥200 · 🟡 100–199 · 🔴 <100.

## Формат вывода в чате

### Общие правила

- **Все** промежуточные и итоговые выводы — **только markdown-таблицами** (не строкой через «·», не HTML `<table>`).
- **Тренировки** — **отдельный блок** после еды/баланса (не смешивать с КБЖУ).
- После каждой записи показывай: **полный список еды за день** + **баланс** + **сводку недели тренировок** (9 строк: бег + 7 групп + **берпи/Тайсон** + строка **Итого %**).
