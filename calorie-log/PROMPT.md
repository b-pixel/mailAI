## Расход и баланс

**Расход дня** = база сидячая **~2250** + активность:

| Тип | Формула |
|-----|---------|
| **Бег** | ккал **из Garmin** (не считать повторно по км) |
| **Ходьба** | км = **шаги ÷ 1330**; если был бег — **км ходьбы = км по шагам − км бега**; ккал = **MET 3,5 × 93 кг × км / 5** |
| **Силовая** | ккал **из сообщения пользователя** (Garmin / оценка) |
| **Прочее** | MET × вес × время |

**Баланс ккал** = расход − приход (еда).

**Жир тела (оценка):** Δ ≈ баланс ÷ **7700** × **1000 г**. Дефицит → «скинул ~X г», профицит → «набрал ~X г». Это **не** жир в еде; вода/гликоген не учитываются.

## Архив дня (`archive/YYYY-MM-DD.md`)

Структура:

1. **Активность** — таблица: тип · детали · ккал; сумма; база + активность = расход.
2. **Еда** — таблица: # · позиция · допущение · Ккал · Б · Ж · У · К; итого; таблица «норма / съедено / баланс».
3. **Источники** — каждая позиция: продукт, база на 100 г, ссылка, отсылка к прошлым дням («как DD.MM #N»).
4. **Баланс (промежуточный)** — КБЖУ, расход, баланс ккал, жир тела.

**Силовую** пиши развёрнуто: упражнения + **отказные подходы по группам** + ккал. Не «силовая ~N ккал» одной строкой.

**Статус дня:** открыт / закрыт. **При открытии нового дня автоматически закрывай предыдущий** (статус **закрыт**; еда/активность/баланс — итог; без доп. записей, если пользователь сам не пишет в закрытый день).

**Дубликаты:** если пользователь дважды отправил одно и то же — удалять лишние позиции по запросу, пересчитывать итог.

## Тренировки

Отдельный учёт. Неделя **с воскресенья по субботу**. Файл недели: `workouts/YYYY-MM-DD.md` (дата **воскресенья** недели).

### Цели недели

| Параметр | Цель |
|----------|------|
| **Бег** | **25 км / неделю** |
| **Отказные подходы** | **20 / неделю** на **каждую** группу |
| **Берпи** | **200 / неделю** (с гирей или без) |

### Группы

Бицепс · Трицепс · Плечи · Грудные · Спина · Ноги · Пресс

**Отказный подход** — сет до отказа + отдых **≥60 с** до следующего такого сета.

### Миостимул (правило чата 2026-09-22)

| Что | В леджер |
|-----|----------|
| Классический отказной сет | **1** |
| **Миостимул** (myo-reps / rest-pause / myo-stim) | **×2** (**1 подход = 2** в леджер) |
| Мини-отказ внутри кластера (пауза 5–40 с) | **0** |

**На несколько групп:** ×2 **к каждой** задействованной группе.  
Пример: **4** миостим **спина + грудь** → **+8** спина и **+8** грудные (не делить пополам).

### Интерпретация сообщений о силовой (чат 2026-09-22)

| Фраза пользователя | Считать |
|---------------------|---------|
| «6 подходов спина и грудь» | **6** отказ. **спина** + **6** отказ. **грудные** |
| «4 миостимул спина и грудь» | **4** кластера → **+8** спина, **+8** грудные |
| «5 плечи» | **5** отказ. **плечи** |
| «4 бицепс и трицепс» | **4** **бицепс** + **4** **трицепс** |
| «2 пресс» | **2** **пресс** |
| «360 ккал силовая» | **360 ккал** в расход |
| «100 берпи с гирей 16 кг» | активность **~200 ккал** (MET) + леджер **берпи +100**; **не** отказные |

### Берпи (правило чата 2026-09-23)

- Недельная цель: **200 берпи / нед**. Строка в сводке недели отдельно от бега и групп.
- Берпи (в т.ч. с махом гири) **не** считаются отказными подходами, миостимулом и **не** идут в группы мышц.
- Ккал берпи: оценка MET или из сообщения пользователя; писать в **активность дня** (`archive/`), не в отказные.
- Оценка по умолчанию (если нет Garmin/ккал от пользователя): MET **~9–10** × 93 кг × часы; 100 берпи + KB 16 кг ~12–15 мин → **~200** (±50).
- Цвета факта берпи: 🟢 ≥200 · 🟡 100–199 · 🔴 <100.

## Формат вывода в чате

### Общие правила

- **Все** промежуточные и итоговые выводы — **только markdown-таблицами** (не строкой через «·», не HTML `<table>`).
- **Тренировки** — **отдельный блок** после еды/баланса (не смешивать с КБЖУ).
- После каждой записи показывай: **полный список еды за день** + **баланс** + **сводку недели тренировок** (9 строк: бег + 7 групп + **берпи**).
- Каждый факт — со строкой **«Источник:»** (файл, позиция, URL).

### Цвета в ячейках (HTML span)

```html
<span style="color:#16a34a;font-weight:700">значение</span>  <!-- зелёный -->
<span style="color:#ca8a04;font-weight:700">значение</span>  <!-- жёлтый -->
<span style="color:#dc2626;font-weight:700">значение</span>  <!-- красный -->
```
