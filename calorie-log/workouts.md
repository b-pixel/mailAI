# Тренировки

Отдельный учёт от калорий. Неделя **с воскресенья по субботу**.

## Цели недели

| Параметр | Цель |
|----------|------|
| Бег | **25 км / неделю** |
| Отказные подходы на группу | **20 / неделю** на каждую группу |
| Берпи | **200 / неделю** (с гирей или без; **не** отказные) |

## Группы мышц

Бицепс · Трицепс · Плечи · Грудные · Спина · Ноги · Пресс

**Отказный подход** — сет до отказа с восстановлением **≥60 с** до следующего такого сета (или явно помеченный пользователем как отказ). Последний подход в серии до отказа тоже считается.

### Конвертация myo-reps / rest-pause / миостимул

Единица леджера = **1 классический отказной подход** (отказ + отдых ≥60 с).

| Что сделано | Кредиты в леджер |
|-------------|------------------:|
| Классический сет до отказа, отдых ≥60 с | **1** |
| **Миостимул** (myo-reps / rest-pause / myo-stim) | **×2** (двойной объём: **1 подход = 2** в леджер) |
| Мини-отказ внутри кластера (пауза **5–40 с**) | **0** (не считать отдельно) |

**Миостимул на несколько групп:** **×2 к каждой** задействованной группе. Пример: **4** миостим **спина + грудь** → **+8** спина и **+8** грудные (не делить пополам).

Пример отжиманий: классика **35 / 25 / 20 / 20 / 15** (все в отказ, отдых ≥60 с) = **5**. **4** миостим на грудные = **8** в леджер грудных.

### Дробный учёт, если названо упражнение

Пользователь пишет **упражнение, число сетов и был ли отказ**. Кредиты по группам считает журнал, не «все мышцы, которые шевельнулись».

Кредит даётся **только отказом** (отказ + отдых **≥60 с**). Общая усталость без локального отказа = **0** по группам.

| Роль в движении | Кредит за 1 отказной сет |
|-----------------|-------------------------:|
| Прямой движитель | **1** |
| Осмысленный синергист | **0,5** |
| Стабилизатор / ниже рабочего порога | **0** |

**Миостимул** умножает уже начисленный кредит группы на **2** (в том числе 0,5 → 1). Группа с кредитом **0** остаётся **0**.

Если пользователь сам назвал группы и числа («6 спина и грудь», «5 плечи») — пишем **его числа**, дробный разбор не подменяет.

Падение повторов внутри серии (30-25-20…) кредиты не режет: каждый сет до отказа = полный кредит этого сета.

**Берпи** в этот разбор не входят: только счётчик **берпи / 200**, группы = **0**.

Стартовый каталог (чат 2026-09-27; новые упражнения дописывать сюда после разбора):

| Упражнение | Условие | Бицепс | Трицепс | Плечи | Грудные | Спина | Ноги | Пресс |
|------------|---------|-------:|--------:|------:|--------:|------:|-----:|------:|
| Брусья | отказ, отдых ≥60 с | 0 | **1** | **0,5** | **1** | 0 | 0 | 0 |
| Отжимания на кольцах (rings dips) | отказ, отдых ≥60 с | 0 | **1** | **0,5** | **1** | 0 | 0 | 0 |
| Подтягивания, прямой хват | отказ, отдых ≥60 с | **0,5** | 0 | 0 | 0 | **1** | 0 | 0 |
| Жим гири от груди вверх | отказ, отдых ≥60 с | 0 | **0,5** | **1** | 0 | 0 | 0 | 0 |
| Отжимания Тайсона | отказ, отдых ≥60 с | 0 | **1** | **0,5** | **1** | 0 | 0 | 0 |
| Махи гантелями (в стороны) | отказ, отдых ≥60 с | 0 | 0 | **1** | 0 | 0 | 0 | 0 |
| Махи гири (свинг) | отказ, отдых ≥60 с | 0 | 0 | 0 | 0 | 0 | **1** | 0 |
| Махи гири (свинг) | без отказа | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| Берпи | без отказа, любая усталость | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| Спринт 100 м, полная выкладка, скорость к финишу падает | отказ ног, отдых ≥60 с | 0 | 0 | 0 | 0 | 0 | **1** | 0 |

Пример: брусья **5** отказных → грудь **5**, трицепс **5**, плечи **2,5**. Жим гири **5×5** в отказ → плечи **5**, трицепс **2,5**. Отжимания Тайсона **50** в отказ (**4** отказных) → грудь **4**, трицепс **4**, плечи **2**. Махи гантелями **2** в отказ → плечи **2**. Махи гири **4** подхода без «в отказ» → группы **0**. Берпи **100** за 8 мин без отказа → берпи **+100**, группы **0**. Спринт **4×100 м** с падением скорости к финишу → ноги **4**, бег **+0,4 км**.

**Спринт с падением скорости** — отказной сет **ног**. Задняя поверхность бедра, ягодичная, прямая бедра и икры — одна группа **Ноги**, поэтому **1** за отрезок, не по единице на каждую из них. Мах руками — стабилизация: плечи, бицепс, трицепс, пресс = **0**. Километры бега пишутся отдельно: **0,1 км** за каждые 100 м. Если скорость к финишу держится и отрезок просто кончился — ноги **0**, только километры.

## Формат записи в дне (архив `archive/`)

Силовую пишем **не** «силовая ~N ккал», а:

| # | Что | Детали | Ккал |
|---|-----|--------|------|
| N | Силовая | упражнения + **отказные подходы по группам**; см. [workouts/…](workouts/) | ~… |

Бег в архиве дня — как раньше (км + ккал). Дублируем км в [workouts/](workouts/).

## Формат вывода в чате

**Отдельный блок таблиц** (после таблицы дня или вместе, но **отдельно**):

1. Запись тренировки за день (если была)
2. **Сводка недели:**
   - строка **дней до конца недели** (включая сегодня; до субботы)
   - строка **последняя тренировка** — **сколько дней назад** + кратко (бег / группы)
   - **таблица целиком** — всегда **все строки**, без сокращений: **Бег, км** + **Бицепс · Трицепс · Плечи · Грудные · Спина · Ноги · Пресс** + **Берпи** (9 строк); колонки: **Факт · Цель · Осталось · Последнее · 2 дн подряд**
   - колонка **2 дн подряд** — если силовая с отказными на эту группу была **вчера и сегодня** (календарные дни подряд); иначе **—**

**Дней до конца недели:** от текущей даты до **субботы** включительно (неделя вс–сб).

**2 дн подряд:** смотрим последние две силовые с отказными по группе. Если даты идут подряд (напр. **14.09** и **15.09**) — в сводке недели ставим **⚠ 14→15** (или **⚠ вчера→сегодня**, если второй день = текущий чат). Ходьба и бег не считаются. Пропуск дня между силовыми сбрасывает серию.

**Последнее:** только **«N день/дня/дней назад»** от текущей даты чата, без календарной даты.

**Цвета** (см. [profile.md](profile.md)):

| Колонка | 🟢 | 🟡 | 🔴 |
|---------|----|----|-----|
| **Факт** отказных | ≥20 | 10–19 | 0–9 |
| **Факт** бег (км) | ≥25 | 13–24 | 0–12 |
| **Факт** берпи / 200 | ≥200 | 100–199 | <100 |
| **Последнее** (дн. назад) | ≥3 | 2 | 1 или **—** |
| **2 дн подряд** | — | — | **⚠** (оранжевый `#ea580c`) если да |
